# Run ZERO TO MILLIONAIRE v0.8

Windows64: place every zero-to-millionaire-windows-v0.8.zip.001/.002/... part
in the same folder. In7-Zip choose Extract on .zip.001, then run
zero-to-millionaire-windows-v0.8/ZeroToMillionaire.exe. Keep the complete folder.
No installer, login, internet, purchases or administrator rights are required.

Normal launches preserve the existing player save at
%USERPROFILE%/AppData/LocalLow/PrototypeWorkspace/ZERO TO MILLIONAIRE/.
Menu contains Tutorial replay, Animation full/calm and Reset. Reset requires
confirmation. Three free starter spins and FREE SPIN recovery prevent deadlock.
SPIN/STOP/SKIP, BUY and menu work with pointer/touch and keyboard focus.

Source: extract all complete-source-v0.8 split parts with7-Zip, open the project
in Unity6000.3.21f1, open Assets/Scenes/Level1.unity and press Play. For isolated
Editor review set ZTM_QA_SAVE_DIR to a fresh local directory before opening
Unity. Do not share a normal Editor profile with a simultaneously running game.

Native local verification uses --ztm-private-profile ABSOLUTE_DIRECTORY, which
is validated under the executable's sibling project .tooling tree. QA reports
and screenshots describe this test mode; normal game launch needs no flags.
Androidv0.8 export/install is deferred; no APK is represented as this release.
