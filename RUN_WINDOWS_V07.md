# ZERO TO MILLIONAIRE — Windows v0.7

1. Скачайте все части архива Windows в одну папку: .zip.001, .zip.002 и остальные. Названия файлов должны совпадать с исходными.
2. Откройте .zip.001 в 7-Zip и выберите «Извлечь». Следующие части отдельно открывать не нужно.
3. В папке zero-to-millionaire-windows-v0.7 запустите ZeroToMillionaire.exe. Оставьте рядом папку ZeroToMillionaire_Data и остальные файлы сборки.

Установка, вход и подключение к сети для игры не нужны. Окно портретное; его размер можно менять. Нажимайте «СПИН», собирайте детали текущего задания и деньги. Покупка становится доступной, когда хватает обоих ресурсов. Изменения комнаты применяются после покупки. Первые три спина бесплатные; при нехватке денег доступен бесплатный способ продолжить.

Прогресс сохраняется на этом компьютере и совместим с v0.6. Чтобы начать заново, откройте меню, выберите сброс прогресса и подтвердите его. Отмена сохраняет текущую игру.

Клавиатура: Tab / Shift+Tab — переход между кнопками, Enter / пробел — действие, Escape — закрыть меню или отменить сброс. Поведение проверено событиями в Editor; физический ввод в Windows пока не проверен: тестовое окно не было активным.

Один уровень: та же комната 9 м² и восемь скромных улучшений. Android v0.7 в комплект не входит.
