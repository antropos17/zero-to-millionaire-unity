# ZERO TO MILLIONAIRE — прототип v0.5

Игра для Windows: один небольшой уровень в неизменной комнате 9 м². Работает без интернета, регистрации и покупок.

1. Распакуйте весь архив Windows в одну папку.
2. Запустите `ZeroToMillionaire.exe`. Оставьте рядом `ZeroToMillionaire_Data`, `MonoBleedingEdge`, `UnityPlayer.dll` и остальные файлы.
3. Вращайте поле кнопкой «СПИН». Каждый нужный символ даёт один фрагмент. «КУПИТЬ» включается, когда хватает **и фрагментов текущей вещи, и монет**. Покупка производится вручную.

Три первых спина бесплатны. Если монеты закончатся, доступен бесплатный восстановительный спин. Все монеты виртуальные. Уровень заканчивается после восьми ремонтов и вещей; комната не расширяется.

Обучение можно пропустить и продолжить после перезапуска. В меню есть «Повторить обучение» — это справка, она не выдаёт наград. Сброс комнаты требует подтверждения. Часть остального интерфейса пока на английском; реплики героини текстовые, без озвучивания.

Прогресс сохраняется в `%USERPROFILE%/AppData/LocalLow/PrototypeWorkspace/ZERO TO MILLIONAIRE/level1-v1.json`. Старое сохранение сохраняет ресурсы и прежние требования текущей покупки; последующие задачи развиваются медленнее. **Перед переходом закройте старую v0.3 самостоятельно:** сейчас она оставлена запущенной с вашим прогрессом. Две версии используют одно обычное сохранение. После записи схемы 5 не открывайте его старой версией.

Готовая папка на этом компьютере: `X:/Projects/ZERO-TO-MILLIONAIRE/Builds/Windows-FINAL-v0.5`. Можно запустить с размером окна 480×960:

```powershell
& 'X:\Projects\ZERO-TO-MILLIONAIRE\Builds\Windows-FINAL-v0.5\ZeroToMillionaire.exe' -screen-fullscreen 0 -screen-width 480 -screen-height 960
```

Для разработки откройте исходники в Unity 6000.3.21f1, сцену `Assets/Scenes/Level1.unity`. Финальная игра собрана из коммита `17f525238b1925819b857f9bfd31cb5ec4062126`; позднейшие изменения — документация и отдельные проверки. Windows-сборка не подписана; внутренний bundleVersion оставлен 0.3.0, v0.5 обозначает ревизию прототипа. Android-сборка отложена; прежние APK сохранены.

Проверены сохранения, полный уровень и портретные размеры. Физическое управление пока не проверено: активна заставка Windows. Известное предупреждение ComputeBuffer при закрытии не скрыто. Подробности и точные границы автоматических тестов: `NATIVE_RELEASE_VALIDATION_V05.md`.
